# Development instructions
Read README.md, docs/ROADMAP.md, docs/ARCHITECTURE.md, docs/MODEL_DESIGN.md, docs/PROJECT_RULES.md and docs/knowledge/graph.json before work. Start at the first unfinished stage. Obtain user approval before implementation or architectural changes. Work one stage at a time. After each stage, update roadmap, graph JSON and Mermaid view in the same commit; record actual file paths, qualified function names, inputs, outputs, calls, dependencies, tests and status. Verify symbols against code; never invent implemented functions. Keep scientific and operational decisions distinct. No secrets, raw SIEM data or private upstream code in this public repository.

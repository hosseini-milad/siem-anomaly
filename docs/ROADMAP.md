## Adaptive anchor expansion (2026-11-25)

The initial 5% anchor budget is a starting seed, not a cap. Each component is compared against current anchors using the configured mixed-similarity threshold (default 0.85). If at least one existing anchor has similarity strictly greater than the threshold, the component is assigned to its nearest qualifying anchors (up to anchor-k). Otherwise the component becomes a new anchor and can represent later components. The bipartite matrix is sparse; each row sums to one and anchor rows self-assign. Reports distinguish initial coverage, components requiring new anchors, number of newly created anchors, final anchor count, and each creation reason. Threshold is an experimental hyperparameter and must be evaluated separately from SCRAC Complete-Link.

## Stage 5 — topology-preserving hierarchical graph compression
Implemented `hierarchy.graph.build_hierarchy` in `hierarchy/graph.py`. Level 0 is the weighted quotient induced by the topology-constrained SCRAC assignment. Subsequent levels use deterministic weighted maximal matching on positive inter-cluster edges, with normalized affinity `w_ij / sqrt(V_i * V_j)` as the priority. Each parent has at most two children; only adjacent nodes in the same original connected component can merge. Symmetric quotient diagonals retain twice the internal undirected edge weight (self-loop weight is diagonal/2); off-diagonal cut weights remain aggregated. Every transition stores child-to-parent IDs and parent-to-children CSR-style offsets/indices. The NPZ stores sparse levels and mappings; JSON stores level metrics and validation flags. CLI accepts original `adjacency.npz`, SCRAC assignment `.npz`, optional original component IDs and output prefix. Five synthetic unit tests are included; the local equivalent suite passed, including stale component-ID rejection. Real 5000-node run, artifact inspection, spectral/distortion evaluation and downstream impact are pending; no real-data acceptance is claimed. Run `python -m pytest tests/test_hierarchy_graph.py -q` and then `python -m hierarchy.graph --graph <adjacency.npz> --assignment <scrac-output.npz> --output-prefix artifacts/graph/hierarchy/scrac_0p750_0p200 --max-levels 6`.
